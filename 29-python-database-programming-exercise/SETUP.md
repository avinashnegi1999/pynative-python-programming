# Hospital practice data

setup.sql contains the source page's SQLite schema and sample records for 4 hospitals and 8 doctors. It contains no answers to the exercises.

Use a fresh practice database and load setup.sql before solving the questions. Python includes sqlite3; MySQL and PostgreSQL are alternative choices from the page. No on-disk database was created or modified.

Exercise 5: experience depends on today's date; the website's example value of 15 is historical.
